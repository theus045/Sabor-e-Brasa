# Sabor & Brasa

Site fictício de restaurante desenvolvido para portfólio, com foco em design moderno, responsividade e boa experiência do usuário.

## Sobre o projeto

O **Sabor & Brasa** é um site de restaurante especializado em carnes e pratos preparados na brasa.

O projeto foi criado com HTML, CSS e JavaScript puro, sem frameworks.

## Funcionalidades

- Hero em tela cheia
- Cardápio com imagens dos pratos
- Seção sobre o restaurante
- Seção de contato
- Botão de WhatsApp
- Menu responsivo para celular
- Animações ao rolar a página
- Layout responsivo
- SEO básico
- Google Maps incorporado

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Responsividade

O site foi desenvolvido para funcionar em:

- Computadores
- Tablets
- Smartphones
